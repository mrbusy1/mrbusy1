# About

Passionate **Software Engineer & Full-Stack Developer** focused on building scalable business platforms, enterprise applications, AI-powered systems, desktop software, automation tools, and modern web experiences.

**Full-Stack Development:** Designing and developing enterprise-grade applications using Laravel, PHP, JavaScript, TypeScript, React, Flutter, MySQL, and modern cloud technologies.

**AI & Automation Engineering:** Creating AI-powered workflows, MCP integrations, intelligent automation systems, custom assistants, local LLM deployments, and productivity-focused solutions.

**Desktop & Business Solutions:** Building ERP, CRM, inventory, finance, project management, file organization, and workflow automation platforms for startups and enterprises.

**Cloud & Infrastructure:** Managing Linux servers, Docker environments, Nginx deployments, Cloudflare integrations, VPS infrastructure, CI/CD pipelines, and self-hosted solutions.

**Open Source & Innovation:** Exploring emerging technologies, software architecture, AI ecosystems, high-performance applications, and next-generation development workflows.
